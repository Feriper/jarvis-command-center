## 🚀 Opções de Deployment Permanente

### 1. Nuvem Híbrida (Vercel + Railway) - Recomendado
- **Frontend**: Vercel (Rápido e Global)
- **Backend**: Railway (Potente e Estável)
- *Instruções detalhadas em `DEPLOYMENT_PERMANENTE.md`.*

### 2. Servidor Dedicado / Oracle Cloud (Máxima Performance)
Se você tem uma instância na Oracle Cloud ou qualquer VPS Ubuntu:

1. Clone o repositório.
2. Dê permissão ao script: `chmod +x deploy-oracle.sh`
3. Execute: `./deploy-oracle.sh`
4. O script instalará Node.js, MySQL, PM2 e configurará tudo automaticamente.
